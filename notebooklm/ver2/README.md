# Bộ tài liệu NotebookLM — ver2 (BẢN HIỆN HÀNH)

Đây là bộ nguồn **mới nhất** để nạp vào NotebookLM. Mỗi file tự-chứa, đọc độc lập.

## Nạp vào NotebookLM
1. Mở NotebookLM → tạo (hoặc cập nhật) notebook.
2. Upload các file `.md` trong thư mục **ver2** này làm sources.
3. Nếu trước đó đã nạp ver1: **xóa source cũ, thay bằng ver2** (tránh mâu thuẫn nội dung).

## Danh sách file
- `00-tong-quan.md` — hệ thống là gì, triết lý, 4 layer, đã online.
- `01-cach-lay-data.md` — nguồn dữ liệu, tự dò sàn, độ tươi, lỗi đã sửa.
- `02-chi-so-va-y-nghia.md` — **ý nghĩa CHI TIẾT từng chỉ số**: Bias dựa vào đâu, "Risk
  vào lệnh 5" nghĩa gì, 5 checklist (long & short), các chỉ số ngữ cảnh.
- `03-cach-su-dung.md` — dùng online, journal PostgreSQL, ghi tay, chat Gemini.
- `04-do-dang-tin.md` — độ đáng tin từng tín hiệu, verdict nghiên cứu.
- `05-cap-nhat-v1-v2.md` — những thay đổi so với ver1.
